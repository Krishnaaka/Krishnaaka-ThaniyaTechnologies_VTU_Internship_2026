# Day13 — Improved Student Dashboard Frontend

Improved frontend UI connecting to the Student API backend.

## How to Run

### 1. Start the API (Day12 backend)
```bash
cd Day12/student-api
npm start   # → http://localhost:3000
```

### 2. Open the frontend
Open `Day13/Frontend/index.html` in your browser.

## Features
- Dashboard with stats cards & branch breakdown bars
- Students table with live search, year filter, sort by marks/name
- Add student form with toast notification
- Delete with confirmation modal
- API online/offline status indicator in header
- Fully responsive with collapsible sidebar
